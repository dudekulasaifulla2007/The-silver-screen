# The Silver Screen 

A full-stack movie ticket booking web application built with **Java, Spring Boot, MySQL, HTML, CSS, and JavaScript**.

## Features

* User Signup & Login
* Movie browsing
* Date & Showtime selection
* Interactive seat selection
* Ticket booking & payment workflow
* My Bookings

## Tech Stack

**Frontend:** HTML, CSS, JavaScript
**Backend:** Java, Spring Boot, Spring Data JPA, Hibernate
**Database:** MySQL
**Tools:** Git, GitHub, Maven, VS Code

## Architecture

```text
Frontend → Spring Boot REST API → MySQL
```
